# NOVA – Intelligent Knowledge Assistant

NOVA is a web-based intelligent knowledge assistant built using Python and Flask. It provides quick responses to user questions using a curated knowledge base and predefined conversational patterns.

## Features

- Interactive chatbot interface
- Knowledge-based question answering
- Predefined responses for common technology topics
- Greeting and help responses
- Handles unknown questions with a fallback response
- Flask-based backend
- Clean and responsive web interface

## Knowledge Domains

NOVA currently provides information about:

- Python
- Flask
- Cloud Computing
- GitHub
- General Knowledge

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Git & GitHub
